# 四隅の手動調整と補正

Issue #25はフェーズ3の手動調整・透視補正部分です。自動四隅検出は未実装です。
実画像の検出精度を確認したとは扱いません。ログイン時間の変更は保留です。

## 操作

1. 授業と回を選び、撮影します。画像全体に四隅の枠が出ます。
2. 左上・右上・右下・左下の丸を板面へ動かします。等倍表示でも操作できます。
   「四隅の位置を微調整」の隅選択と内側へ動かすボタン、丸のキーボード矢印操作も使えます。
3. 「補正して確認」で長方形に補正します。文字の仕上がりを等倍で確認します。
4. 修正するときは「四隅の調整に戻る」で元画像へ戻します。四隅を変更したら再度補正が必要です。
   「画像全体に戻す」で初期の枠へ戻せます。
5. 「保存して次の撮影」で補正後のJPEGだけを端末内へ保存し、前面でDriveへ送ります。
   送信完了を待たず次を撮れます。未送信の保持・再送・撮影時の保存先は従来と同じです。

交差・重複・極端に狭い枠はエラーになり、保存できません。四隅を広げて再試行します。
補正中は四隅や保存の操作を止め、「補正を中断」で調整へ戻れます。
裏へ移った場合も補正を止め、確認中の元画像を残します。
保存失敗時には補正画像と元画像を残して再試行できます。
保存成功または撮り直しで両canvasを解放します。元画像をIndexedDB・Driveへ送りません。

## 補正方法と制限

外部ライブラリを追加せず、四隅から求めた透視変換で出力の各画素を元画像へ対応付け、
近傍4画素で補間します。出力の辺は選択範囲の長い辺から求め、不必要な拡大を避けます。
長辺最大4096・最大1200万画素に収めるため、それ以上の画像は縮小します。
縦横比は四辺からの推定なので、実際の板面の正確な比率を保証するものではありません。
16行ずつ処理して画面へ制御を戻します。端末のメモリ不足や中断では成功扱いしません。
色調・照明・ブレの改善は行いません。撮影中の画像は公開リポジトリやIssueへ添付しないでください。

## 確認

自動テストでは数式とコード内の合成画素だけを使い、恒等変換・台形の対応点・補間・
範囲検証・出力上限・補正状態と保存可否を確かめます。画像ファイルは追加していません。
