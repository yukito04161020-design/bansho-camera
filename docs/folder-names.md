# フォルダ名と回数（Issue #14）

`public/folder-logic.js`はGoogle、画面、端末内保存に依存しない純粋な関数です。
Driveから取得した、**選択した授業だけ**の回フォルダ名の配列を渡します。
授業の違いは呼び出し元で一覧を分けてください。

```js
import { chooseSessionFolder, folderPath } from "./folder-logic.js";
const capturedAt = "2026-09-30T10:00:00+09:00";
chooseSessionFolder(["第01回_2026-09-29"], capturedAt);
// "第02回_2026-09-30"
folderPath({ className: "数学Ⅰ", session: 2, capturedAt });
// ["板書", "数学Ⅰ", "第02回_2026-09-30"]
```

`sessionFolderName(session, capturedAt)`は回フォルダ名、`japanDate(capturedAt)`は
日本時間の日付、`classFolderName(className)`は検証済み授業名を返します。
パスは区切り文字を含む文字列にせず、Driveで階層ごとに使える名前の配列です。

## 規則

- 日付は常に`Asia/Tokyo`。日時はDate、Unixミリ秒、タイムゾーン付きISO日時
  （秒まで、任意の1〜3桁ミリ秒、`Z`または`±HH:MM`）を受け付けます。
  タイムゾーンなし、存在しない日付、不正な時刻は拒否します。
- 回数は1以上の安全な整数。1〜9回は01〜09、10回以上は先頭に0を足しません。
- 同日に既存フォルダがあれば再利用。ない場合は有効な既存名の最大回＋1。
  撮影しなかった期間や欠番は加算しません。撮影が過去の日でも最大回＋1です。
- 第3引数`manualSession`を指定すると自動提案より優先します。
  同じ回が**別の日**に存在する場合は`FolderNameError`の`reason: "collision"`。
  上書き・混在せず、呼び出し元で利用者に別の回を指定してもらいます。
  同じ日・同じ回は再利用できます。同じ日で別の回への変更も可能です。
- 同日に複数の有効な名前がある場合、自動提案は最大回を採用します。
  手動修正の履歴が配列の並び順に左右されません。
- 授業名はそのまま保持。空・前後の空白・`.`・`..`・`/`・`\\`・`／`・制御文字は拒否。
  自動置換で別の授業と同名になるのを避けます。
- 規則外のフォルダ名は無視。実在する西暦0001〜9999年の日付だけを扱い、
  第00回、桁不足、余分な先頭0、整数の精度限界を超えた名前も無視します。
  最大安全整数＋1が必要ならエラーにし、丸めて重複する名前を作りません。

入力エラーは`FolderNameError`の`reason`（`className`、`timestamp`、`session`、
`collision`、`folders`）で判定できます。引数や既存配列を変更しません。
フォルダ作成・一覧取得・同時作成の排他制御・画面は後続の本実装で扱います。

## 確認

`npm test`で命名、同日・別日・休講、JST午前0時、年越し・うるう年、手動優先・衝突、
無効な既存名と入力を確認します。子プロセスの`TZ`を東京・UTC・ロサンゼルスに変え、
同じ瞬間が同じ回になることも検証します。このIssueには実機チェック項目はありません。
