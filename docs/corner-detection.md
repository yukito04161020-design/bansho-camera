# 四隅検出と精度測定（Issue #33）

検出は素のJavaScriptで実装し、追加の依存は使わない。長辺1000px以下の画像から
明暗領域の凸包を求め、最大の自然な四角形を元画像の座標へ戻す。
面積15%未満、交差、極端なゆがみ、細すぎる辺などは採用せず、画像全体の枠に戻す。
検出結果を使った補正プレビューは自動で作り、元画像は保存しない。
合成画像の検証は `npm test` で行う。実画像での精度は未確認。

## 非公開サンプルの測定

非公開リポジトリをこの公開リポジトリの外へ取得し、その中に画像と `corners.json` を置く。
正解座標は元画像のピクセル座標で、左上・右上・右下・左下の順に記録する。

```json
[
  {
    "file": "sample-001.jpg",
    "corners": [{"x": 100, "y": 80}, {"x": 1700, "y": 120}, {"x": 1650, "y": 900}, {"x": 90, "y": 950}]
  }
]
```

```sh
CORNER_SAMPLES_DIR=/path/to/private-samples npm run measure:corners
```

表示されたローカルURLをブラウザで開く。ブラウザの画像デコーダとCanvasで
JPEG・PNGなどを読み、アプリと同じ検出コードで測定する。
結果は画面とターミナルへ表示し、測定後にローカルサーバーを終了する。
全四隅の誤差が元画像の対角線の3%以内なら正解、正解率90%以上なら成功（終了コード0）、
未達または測定失敗は終了コード1。結果のrowsはサンプルの配列順を表す。
目標は仮の値で、実画像の結果を見て見直す。

環境変数未指定・ディレクトリなし・正解データなし・サンプル0件なら
`SKIP` を表示して終了コード0で終了する。壊れた正解データや欠損画像は失敗とし、
スキップで隠さない。画像はメモリとローカル通信でのみ扱い、リポジトリへコピーしない。
測定サーバーは127.0.0.1のみで待ち受け、指定された画像と検出用の2モジュールだけを配信する。
これは開発用の測定スクリプトで、PWAの配信物には含めない。
