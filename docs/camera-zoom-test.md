# Issue #9：レンズ・ズームによる可読性の検証

Issue #3では3024 × 4032 pxの映像でも教室後方から板書を読み取れなかったため、
同じ試作で望遠カメラやズームを試します。実機結果はまだ未確認です。
結果が出るまでは設計書4.1・7章の可読性の判断を変更しません。

## 試作の動作

- カメラ開始後に`enumerateDevices()`で許可後の一覧を取得します。
  カメラを切り替えても一覧を取り直し、使用中のトラックの`label`を表示します。
  名前が取得できなければその旨を表示します。
- 一覧にはブラウザが公開した映像入力を表示します。前面を含む場合がありますが、
  取得時には選んだ`deviceId`と背面の`facingMode: { exact: "environment" }`を要求します。
  前面は選ばず、名前と実際の映像で背面レンズを確認してください。
- `getCapabilities().zoom`が有効なら、その最小値・最大値・刻みでスライダーを操作できます。
  操作を終えると`applyConstraints()`で倍率を要求します。解像度・カメラの制約も維持します。
  非対応の場合は「ズーム操作を利用できません」と表示します。
- 倍率は`getSettings().zoom`で読み戻します。指定が反映されない場合や、現在倍率を
  読めない場合は区別して表示します。ブラウザによるズームの方式は実機で判断します。
- 選んだカメラと最後の倍率だけを`localStorage`に記憶します。
  開き直して「カメラを開始」を押すと復元します。範囲が変わった倍率は範囲内に収めます。
  記憶したカメラが見つからなければ背面の自動選択に戻し、案内します。
  設定の保存を拒否された場合も、その画面での検証は続けられます。
- 「映像」は`videoWidth × videoHeight`の実寸、「要求」は希望値です。
  撮影は映像の1コマを縮小せずcanvasに切り出し、等倍で確認できます。
  画像確認画面にも撮影時のカメラ名・倍率を表示します。

保存・ログインは追加していません。画像はメモリ内のcanvasに表示するだけです。
カメラに戻る操作やページを閉じる操作で画像は失われます。
板書の画像は公開リポジトリ、Issue、PRに添付しないでください。

## マージ後のiPhoneでの確認手順

1. ActionsのPages公開成功を確認し、ホーム画面のアイコンからアプリを開き直す。
   「カメラの解像度を検証する」を開き、見出し「レンズ・ズームの検証（Issue #9）」を確認する。
   版表示が公開されている場合は版番号も記録する。
2. 「カメラを開始」を押し、許可する。背面映像と実際の解像度が表示されることを確認する。
3. 「カメラ・ズームを選ぶ」を開き、一覧に出る名前を記録する。
   背面望遠がある場合は選び、映像と画面のカメラ名が変わることを確認する。
   一覧が出ない場合や望遠が公開されない場合も、その結果を記録する。
4. ズーム操作が可能ならスライダーを動かす。表示された現在倍率を記録する。
   非対応、指定が反映されない、現在倍率が読めない場合はその表示を記録する。
5. 教室後方の普段使う席から、板面が映像の横幅いっぱいになるようレンズ・倍率を選ぶ。
   板面全体が収まるか、寄せられる上限、実際の「映像」の解像度を記録する。
6. 黒板・スクリーンをそれぞれ「1コマを撮影」する。音が鳴らないことを確認する。
   「撮影画像」の実寸、カメラ名・倍率を記録し、「等倍で確認」でスクロールして文字が読めるか判断する。
7. 「カメラに戻る」で次の撮影を行う。縦・横で表示と操作を確認する。
   選択欄は閉じて撮影でき、非対応カメラではスライダーが無効になることも確認する。
8. 望遠や倍率を選んでからアプリを閉じ、開き直して「カメラを開始」を押す。
   前回のカメラと倍率が復元されることを確認する。
9. 裏に回るとカメラが停止し、戻って「カメラを開始」で再開できることを確認する。
   自動消灯防止の表示・動作も確認する。

## Issue #9に記録する結果

複数のレンズ・倍率を試した場合は、撮影条件以下を条件ごとに記録してください。
画像は添付せず、数値と可読性だけを記録します。

```text
確認日：
iPhone機種／iOSバージョン：
確認したPR／コミット／表示された版番号（ある場合）：
起動方法：ホーム画面から
一覧に出たカメラ名：
撮影位置・板面までの距離：
撮影条件（選んだカメラ名／現在倍率／縦か横）：
ズーム操作：対応（範囲：）／非対応／指定が反映されない／現在倍率を取得不可
板面を横幅いっぱいに収められる：可／不可（補足）
実際の映像解像度：
撮影画像解像度：
黒板の文字：読める／読めない（小さい文字などの補足）
スクリーンの文字：読める／読めない（補足）
シャッター音：なし／あり
設定の復元：可／不可
等倍表示・次の撮影・縦横の操作：
裏から戻った後の再開・自動消灯防止：
総合結果・気付いたこと：
```

読めた場合はレンズ・倍率を設計書4.1と7章に反映してからIssue #5へ進みます。
読めない場合は撮影方式の見直しを設計書で検討してから進みます。

## 自動確認

`npm test`で一覧整形、設定の保存・復元と不正値、倍率の範囲・刻み、制約の維持、
倍率の読み戻し、選択カメラの要求と消失時の復旧、許可拒否を確認します。
Issue #3の背面・高解像度要求と縮小しないフレーム切り出しのテストも維持します。
自動確認では偽のAPIを使います。望遠レンズの公開状況、実際の倍率・解像度、
可読性・無音はiPhoneでの結果が必要です。
